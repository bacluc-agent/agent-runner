## Root cause: phpunit conflict

- paratest v7.24.0 raised the requirement to `phpunit ^13.3` ([#1123](https://github.com/paratestphp/paratest/pull/1123)); v7.24.1 only fixes the `--do-not-cache-result` deprecation ([#1128](https://github.com/paratestphp/paratest/pull/1128)) — a no-op for ecamp3, which uses only `--passthru-php` and `-p 4`.
- ecamp3 pins `phpunit/phpunit` 13.2.6 exactly in `api/composer.json`, so `composer update brianium/paratest` cannot resolve 7.24.x without also bumping phpunit.
- PHP constraint `~8.4||~8.5` of paratest 7.24.1 is fine (ecamp3 requires PHP >=8.5.5).
