## 6 Root cause carried

Unchanged from prior bisection:

- Playwright 1.63 / Firefox 155 `modulepreload` behavior: missing route chunk
  (`CampCreate-*.js`) no longer throws a catchable chunk-load error that the
  app's stale-deployment reload handler listens for; `window.marker` survives
  navigation so `markerSurvived` stays `true`.
- No `router.onError` fallback for failed dynamic imports; handler only covers
  the Chromium/WebKit error shape.
- Introduced by Playwright bump commit `337a77a5` (`Update playwright to
  v1.63.0`), merged via https://github.com/ecamp/ecamp3/pull/10692
  (merged 2026-09-13T16:25:02Z).
